# NIGHT

*A quiet place on the internet.*

**One planet. One room. One Earth rotation.**

Night is a deliberately minimal social experience built around a single live global room called **EarthStation**.

Instead of feeds, followers and algorithms, Night explores a slower way to meet people.

Every person receives one permanent identity called a **CavoID**.

Every profile contains a single public **Beacon**.

Messages disappear after one Earth rotation.

---

## Principles

- One room
- One identity
- One Beacon
- No likes
- No followers
- No advertising
- No endless scrolling

---

## Features

- EarthStation
- CavoID
- Beacon
- Directory
- Sidereal Time
